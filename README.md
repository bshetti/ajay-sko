# main-stage

Elastic Observability SKO FY27 presentation — built with [fuckSlides](https://github.com/bahaaldine/fuckslides).

## Start

```bash
npm run serve
```

Opens at **http://localhost:3000**

## Navigate

| Key | Action |
|-----|--------|
| `→` / `Space` | Next slide |
| `←` | Previous slide |
| `G` | Slide overview (drag to reorder, `↑↓←→` to navigate, `Enter` to jump) |
| `T` | Filmstrip |
| `F` | Fullscreen |
| `Esc` | Close overlay |

Reordering in the overview auto-saves back to `fuckslides.config.js`.

## Push changes

git add -A && git commit -m "your message" && git push origin main
